# 电力系统暂态分析

碎碎念： 写于2026年11月。距离上一次接触电力系统暂态分析相关的知识，已经快一年了。今天偶然整理起以前的文件夹，翻到当时的笔记，发现自己对某些知识点依然印象深刻，也回想起一些当时学习这门课的思考与感悟。于是决定趁着这个机会，把之前学习过程中的一些想法重新梳理一下。

整体来说，这门课分了3个部分，分别是3个老师讲（李yj老师、王jx老师、杨sh老师）。用一句话来概括这门课就是“电力系统受到扰动后，如何利用电机与电网的数学模型，分析系统的电气响应和动态演变，并判断系统是否稳定？” 

1. 李老师部分 - 第七章：电机数学建模，核心问题是“怎样描述发电机的物理特性？”，产出是【数学方程、参数方程、等值模型】
2. 王老师部分 - 第八、九章：故障分析，核心问题是“故障后，电气量如何变化？”，产出是【短路电流、节点电压、序分量】
3. 杨老师部分 - 第十章：稳定性分析，核心问题是“受扰后的系统如何运动，能否保持稳定？”，产出是【稳定性判据、功角轨迹、临界切除条件】

## Part1:第七章——电机数学建模
这一章节的核心思路就是【从物理原理推导数学模型，再通过合理假设逐步简化】。先完整描述物理系统，再通过坐标变换、参数替换和合理的假设，得到适合求解的问题（like“数学建模”）

课本上的知识点可能比较散，但是我们可以梳理一条主线逻辑：转子运动方程——abc坐标下同步电机方程——dq0坐标下同步电机方程——引入电机参数与暂态电动势——简化模型——稳态方程和相量图。

这些公式，都可以从一个核心问题出发理解、串联：我们如何从同步电机的基本物理规律出发，一步一步建立出既能够描述电机暂态过程，又方便实际工程计算的数学模型？

于是，我们可以得到整条知识链的内在逻辑。

1. 转子运动方程：从机械运动出发，建模发电机的加速、减速过程（物理建模）。
2. abc坐标下的电机方程：当机械功率与电磁功率不平衡时，发电机转子的转速和功角就会发生变化。于是，我们可以推导出电机内部的电磁关系。abc是定子，f是转子，DgQ是阻尼（等值）绕组。这里分为了电压方程和磁链方程，可以复习一下《电机学》。
3. dq0坐标下的电机方程：已经建立了电磁方程（abc），但原始坐标下的方程太复杂，需要改变数学描述方式。我们利用park变换，将abc坐标系转换到dq0，这样我们方程就从时变常数变成了定常数。但需要知道的是，Park变换改变的是数学坐标，本身没有物理意义，只是数学上的简化。
4. 引入电机参数、暂态电动势：方程虽然变得更容易处理，但仍有大量绕组参数和内部变量，需要把它们整理成适合工程使用的形式。Xd, Xd’, Xd’’。需要理解“为什么需要引入这些参数？它们分别对应什么物理约束和动态过程？” 这里涉及到大量的方程，但都能从物理意义入手，然后推导出每一条方程。
5. 简化模型：课本的p304-306。可以自己推导一遍所有的方程，就能理解了。
6. 稳态方程和相量图：课本图7-7，p207的例7-1。

## Part2:第八、九章——故障分析
这两章的核心思维是【把故障转化为有明确边界条件的网络求解问题】。也就是把故障类型、网络结构、电压电流的约束都转化为可计算的等值电路。

两章节对应两条知识线。第八章【对称短路故障】的核心是三相短路实用计算；第九章【不对称故障】的核心是利用对称分量法，把不对称三相问题转化为序网络问题。

考题相对来说比较固定，就是作业那些类型。但还是有很多东西是值得思考的：

### 简单电路的短路过程？
以电压恒定的交流电源供电、故障后参数固定的 \(R\!-\!L\) 电路为例，短路电流可以写成：
\[
i(t)=i_{\mathrm{周期}}(t)+i_{\mathrm{非周期}}(t)
\]
周期分量由故障后的\textbf{电源}和\textbf{电路参数}决定；非周期分量则与故障发生时的\textbf{初始条件}有关，并随时间衰减。故障发生在电压波形的不同位置，非周期分量的初值也会不同。

这部分的物理逻辑是：电路结构突然改变了，但电感电流需要满足连续性，因此实际响应还要包含一个与初始条件有关的暂态分量。（这个在电路课已经讲过很多遍了）

### 为什么又要研究同步发电机的短路过程？
因为前面采用了较简单的电源模型，而实际同步发电机在短路后，内部电磁状态也会变化。这正好接上第七章，第七章解释了暂态、次暂态参数从哪里来；第八章开始利用这些参数解释短路电流。同步发电机发生短路时，其电磁暂态还会使周期分量的包络发生变化，表现出次暂态、暂态和稳态特性。这里就引出了一个比较重要的物理量——Ik''，初始周期分量的有效值。

### “实用短路计算”？
工程题目往往只要求某些关键结果。这里重要的物理量有初始周期分量有效值 \(I_k''\)，冲击电流 \(i_{\mathrm{sh}}\) 等。

这一章的结构很清楚：稳定性的基本理论——建立DAE——小干扰/大干扰分析——提高稳定性的措施。也就是，在电机动态方程和网络约束的基础上，研究扰动后系统的运动趋势与稳定条件。
